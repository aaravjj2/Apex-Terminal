# Demo Runbook

Follow these steps to reproduce the demo environment or generate the submission media.

## Prerequisites
- Docker (optional, if running containerized)
- Python 3.11+
- Node.js 18+

## Quick Start (Demo Mode)

We have created a single script to launch the entire stack in "Demo Mode" with deterministic mock data.

```bash
# 1. Install dependencies (if not already done)
# Backend
cd phase1 && python -m venv venv && source venv/bin/activate && pip install -r requirements.txt
# Frontend
cd frontend && npm install

# 2. Run the Demo
./scripts/run_demo.sh
```

This will:
- Set `E2E_MODE=true` (forces mock data).
- Start the Backend (Port 8000).
- Start the Frontend (Port 5100).
- Open `http://localhost:5100` to view the app.

## Generating Media Assets

To automatically capture the screenshots and video used in the submission:

```bash
# Ensure the demo is running (./scripts/run_demo.sh)

# Switch to frontend directory
cd frontend

# Run the media generation test
npx playwright test tests/e2e/devpost_media.spec.ts
```

Artifacts will be saved to `devpost_media/`:
- `images/`: High-resolution screenshots.
- `video.webm` (renamed from random filename): Full session recording.

## Troubleshooting
- **Port Conflicts:** Ensure ports 8000 and 5100 are free.
- **Data Missing:** If charts are blank, ensure `data/sample_ticks.csv` exists (it is auto-generated by `generate_mock_csv.py`).
