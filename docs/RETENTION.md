# Apex Terminal — Retention Policy
**Wave 83 | Effective: 2026-02-23**

---

## 1. What Lives in the Repo (ALLOWED to commit)

| Category | Path | Notes |
|----------|------|-------|
| Source code | `frontend/src/`, `phase1/services/`, `backend/` | Always commit |
| Configuration templates | `keys.env.example`, `infrastructure/docker-compose.yml` | No real secrets |
| Documentation | `docs/`, `README.md`, `tasks.md` | Always commit |
| Scripts | `scripts/` | Always commit |
| Tests | `frontend/tests/`, `phase1/tests/`, `backend/tests/`, `tests/` | Always commit |
| Static assets | `frontend/public/` | Always commit |
| Migration docs | `docs/migration/W*.md`, `docs/migration/W*.txt`, etc. | Always commit |

---

## 2. What Stays LOCAL (NEVER commit)

| Category | Path | Why |
|----------|------|-----|
| Secrets | `keys.env`, `phase1/keys.env` | API keys, never commit |
| Build outputs | `frontend/dist/`, `build/`, `.next/` | Regenerated by CI |
| Python venv | `.venv/`, `venv/`, `env/` | Regenerated, large |
| Node modules | `node_modules/`, `frontend/node_modules/` | Regenerated by npm |
| Proof packs | `artifacts/proof/` | Generated locally, large |
| Test results | `test-results/`, `playwright-report/` | Generated during test runs |
| Logs | `logs/`, `*.log`, `*.out` | Runtime generated |
| Databases | `*.db`, `*.sqlite`, `phase1.db` | Runtime state |
| ES data | ES data directory | Runtime state |
| Python caches | `__pycache__/`, `.pytest_cache/` | Regenerated |
| Windows ADS | `*Zone.Identifier` | Windows metadata noise |
| AI agent configs | `.agent/`, `.agents/`, `.cursor/`, `.claude/`, etc. | Local tooling |

---

## 3. Proof Packs

Proof packs live under `artifacts/proof/<timestamp>-<description>/` and are **never** committed.

They contain:
- Gate output logs (`gate-tsc.txt`, `gate-vitest.txt`, etc.)
- Playwright test results and videos
- Determinism comparison files
- MANIFEST.md + manifest.json

Proof packs are shared separately (zip, cloud storage, etc.).

---

## 4. Enforcement

- `.gitignore` covers all forbidden categories (see `.gitignore`)
- `scripts/assert_no_tracked_bloat.ps1` — fails CI if bloat sneaks in
- `tests/test_repo_sanity_no_tracked_artifacts.py` — pytest sanity check
- Pre-commit check: `scripts/clean_workspace.ps1 --dry-run` before each commit

---

## 5. Cleanup

Run `scripts/clean_workspace.ps1` to remove local bloat safely.

This script:
- Deletes `__pycache__/`, `.pytest_cache/`, `.mypy_cache/`, `.ruff_cache/`
- Deletes `test-results/`, `playwright-report/`
- Deletes `*.log`, `*.out` (except `keys.env`)
- Does NOT touch `keys.env`, source code, or committed files
