## Open-Source Compliance

### Automated License Auditing

The project uses automated tools to ensure license compliance:

| Tool | Purpose | Run |
|------|---------|-----|
| `license-checker` | Audit all npm dependency licenses | `npm run licenses:check` |
| `license-checker --production` | Audit runtime deps only | `npm run licenses:prod` |
| `license-checker --failOn` | CI gate: fail on copyleft licenses | CI pipeline |

### Forbidden Licenses

The following license families are not permitted as dependencies:

| License | SPDX | Reason |
|---------|------|--------|
| GNU GPL v2/v3 | `GPL-2.0`, `GPL-3.0` | Copyleft; would require open-sourcing derivative works |
| GNU AGPL v3 | `AGPL-3.0` | Network copyleft; same as GPL plus network use trigger |
| GNU LGPL v2.1/v3 | `LGPL-2.1`, `LGPL-3.0` | Weak copyleft; dynamic linking exception is ambiguous for bundled JS |
| SSPL | `SSPL-1.0` | Server-side copyleft |
| Commons Clause | _(non-standard)_ | Restricts commercial use |
| BUSL | `BUSL-1.1` | Time-delayed open source; initial restriction |

### CI Enforcement

```yaml
# .github/workflows/licenses.yml
- name: Check licenses
  run: npx license-checker --failOn 'GPL-2.0;GPL-3.0;AGPL-3.0;LGPL-2.1;LGPL-3.0'
```

### Generating Attribution File

```bash
npx license-checker --json --production > THIRD_PARTY_LICENSES.json
```

This file is included in production builds under `/licenses.json`.
